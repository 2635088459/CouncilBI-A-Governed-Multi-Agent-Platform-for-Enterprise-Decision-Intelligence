# Final Version Spec Index

This folder contains the final-version SDD + TDD specification package for the Governed Multi-Agent ChatBI Platform.

- English specs: [en/README.en.md](en/README.en.md)
- Chinese specs: [zh-CN/README.zh-CN.md](zh-CN/README.zh-CN.md)

The specs are derived from the final delivery roadmap:

- English roadmap: [../../system_design/final-version/en/09-final-delivery-roadmap.en.md](../../system_design/final-version/en/09-final-delivery-roadmap.en.md)
- Chinese roadmap: [../../system_design/final-version/zh-CN/09-final-delivery-roadmap.zh-CN.md](../../system_design/final-version/zh-CN/09-final-delivery-roadmap.zh-CN.md)

Every spec follows SDD + TDD:

1. SDD: define purpose, scope, actors, design decisions, requirements, contracts, and boundaries.
2. TDD: define acceptance criteria, unit tests, integration tests, negative tests, performance tests, and traceability before implementation.
